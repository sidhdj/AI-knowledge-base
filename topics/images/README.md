# 图片素材存放区

这个文件夹存放图片，供 AI 视觉模型读取学习。

## 支持的格式

`.png` / `.jpg` / `.jpeg` / `.webp` / `.gif`

## 命名建议

- 有意义的名字比 `1.jpg` 好，例如 `角色设计-主角.png`、`场景-雨夜街道.jpg`
- 同一系列可以建子文件夹，例如 `topics/images/角色设计/`

## AI 使用说明

- 描述图片时，结合文件名和周围上下文理解图片用途
- 如果有配图的说明文档，放在图片旁边，例如 `角色设计-主角.png` + `角色设计-主角.md`
