# 小说原文存放区

这个文件夹存放小说原文，目的是让 AI 阅读学习。

## 命名建议

- `书名-作者.md`，例如 `三体-刘慈欣.md`
- 如果文件太长，可以分章节：`三体-第1章.md`、`三体-第2章.md`

## AI 使用说明

AI 读取本文件夹内容时，应重点学习：
- 叙事视角和文风
- 人物对话风格
- 情节节奏和结构
- 描写手法（环境、心理、动作）
