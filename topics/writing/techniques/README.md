# 写作技巧笔记区

这个文件夹存放从小说中提炼出的写作技巧总结。

## 用途

AI 读完 `novels/` 里的小说后，把分析出的写作规律整理成笔记存到这里，例如：
- `人物塑造技巧.md`
- `对话写作技巧.md`
- `悬念与节奏控制.md`
- `环境描写手法.md`
