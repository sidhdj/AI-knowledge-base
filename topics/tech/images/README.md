## topics/tech/images/

这里放科技/硬件文档的辅助配图（充电曲线图、跑分截图、参数表截图等）。

### 命名规范

```
{品牌}_{型号}_{图内容}.{扩展名}
```

示例：

| 文件名 | 说明 |
|---|---|
| iQOO_Neo11_充电曲线图.png | iQOO Neo11 的充电曲线 |
| iQOO_Neo11_跑分.png | iQOO Neo11 的跑分截图 |
| iQOO_Neo11_屏幕实测.jpg | iQOO Neo11 屏幕测试数据 |
| OnePlus_13_续航.png | OnePlus 13 的续航测试图 |

### 上传约定

- 原图直接上传，不要 AI 生成、不要压缩加工
- 一张图一个文件，不要拼图混放
- 传完告诉我一声，我把它引用到对应的 markdown 文档里
