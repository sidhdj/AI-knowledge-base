# iQOO Neo8 参数汇总

> 设备型号：V2301A

## 核心参数速览

- 第一代骁龙 8+ + Adreno 730
- 6.78 英寸 AMOLED，最高 144Hz
- 5000mAh 双电芯电池 + 120W 超快闪充
- 5000万像素主摄（OIS）+ 200万虚化镜头
- LPDDR5 + UFS 3.1
- 最高可选 16GB + 512GB

> 注：不同存储、配色版本的机身厚度和重量可能存在差异；具体参数以官方对应版本页面及实际销售版本为准。
