# 收件箱 inbox

这里是临时缓存区。您可以随意把文件传到这里，不需要考虑分类。

## 使用方法

1. 打开 GitHub 网页，进入本文件夹
2. 点击 "Add file" -> "Upload files"
3. 把文件拖进来，点 "Commit changes" 保存
4. 告诉管理员（AI）您上传了什么，管理员会帮您整理到对应目录

## 支持的文件类型

- 文本：.md / .txt / .docx
- 图片：.jpg / .png / .jpeg / .webp / .gif
- 小说：.txt / .md / .epub
- 其他：任意格式都可以先扔这里

## 整理规则

| 文件类型 | 整理后移动到 |
|---|---|
| 小说原文 | topics/writing/novels/ |
| 图片/手绘 | topics/images/ |
| 写作技巧相关 | topics/writing/techniques/ |
| 编程相关 | topics/programming/ |
| AI/机器学习相关 | topics/ai-ml/ |
| 工具相关 | topics/tools/ |
| 政治党建相关 | topics/political/ |
| 杂记/想法 | topics/notes/ |

## 注意

- 这里的文件是临时的，整理后会从这里删除
- 文件名随意取，整理时管理员会重命名为标准格式
