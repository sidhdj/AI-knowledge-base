## 简介

骁龙® 8 至尊版 第五代移动平台是性能的巅峰之作，带来顶尖的使用体验和个性化的智能体AI。

搭载第三代高通® Oryon™ CPU——全球最快的移动CPU，这款强劲的处理器开创了破纪录的速度和无与伦比的能效。从闪电般的应用启动、即时多任务处理，到快节奏的游戏和响应迅速的移动内容创作，尽享流畅性能。

基于极速的高通AI引擎，搭载端侧智能体AI助手，能够理解并适应你的行为，为你带来高度个性化的体验。凭借新增的AI加速器和64位内存架构，升级后的高通Hexagon NPU和感知中枢（Sensing Hub）实现了端侧个性化，让你喜爱的应用能够代你行动，提供量身定制的推荐。此外，凭借先进的AI功能和提升的能效，你将享受更出色的照片、视频、通话等体验。

骁龙8至尊版第五代带来升级，引入高通® Adreno™ 高性能内存（HPM）——我们行业领先的内存缓存解决方案，提供18MB专用内存，以更低功耗实现革命性的视觉渲染。同时，凭借瓦片内存堆（Tile Memory Heap）和网格着色（Mesh Shading），玩家可以更智能地延长游戏时间，全面的骁龙 Elite Gaming™ 特性就此完善。

搭载AI赋能的摄像头和全新的骁龙 Audio Sense麦克风，让你将专业摄制团队的威力装进口袋，轻松捕捉电影级画面，搭配录音棚级音质。此外，自动对焦、自动曝光、自动白平衡等情境感知功能，让每一次拍摄都完美无瑕。

体验AI优化的5G、Wi-Fi 7、蓝牙®无线技术和UWB的最新进展——无论你是在外游戏、进行近乎即时的数据备份，还是在几乎任何地点实现最高生产力。骁龙8至尊版超越想象——而此刻的你，亦如此。

## 六大优势

### 1. 顶尖性能

主频高达4.74GHz，第三代高通Oryon CPU性能提升20%，CPU能效提升35%；Adreno GPU图形性能提升23%，GPU能效提升20%。凭借16%的SoC整体功耗节省，享受更持久的持续性能表现。

### 2. 按你的需求行事的智能体AI

解锁能够理解并适应用户习惯、偏好和对话的智能体AI助手，提供个性化体验——同时保障用户隐私。这得益于我们速度提升37%的Hexagon NPU，结合高通感知中枢全新的端侧AI学习功能：个人知识图谱（Personal Knowledge Graph）和个人抄写员（Personal Scribe）。

### 3. 以专业水准捕捉你的艺术构想

全球首款支持高级专业视频（APV）编解码器录制的移动平台，可拍摄堪比电影摄影机输出的超高画质高码率素材，支持专业级后期制作流程，让你完全掌控自己的艺术构想。此外，骁龙8至尊版第五代是首款配备三颗20位ISP的移动平台，可捕捉4倍的动态范围，呈现细节更丰富、高光和阴影更出色的精彩照片。

### 4. 更智能地游戏，而非更费力地游戏

我们全面的骁龙 Elite Gaming 特性，结合对虚幻引擎5的完整支持，带来最具沉浸感、视觉效果最震撼的场景，成就无与伦比的移动游戏体验。此外，通过瓦片内存堆（Tile Memory Heap）最大化你的游戏时间，而网格着色（Mesh Shading）支持实现更智能的GPU驱动渲染，进一步节省功耗。

### 5. 无限音效

高通® 扩展个域网技术（XPAN）全屋全楼覆盖，现在当你远离设备时，可通过耳机与AI助手进行完整交互；而高通® aptX™ 无损技术提供24位、96kHz的无损无线音乐串流，带来无束缚的听觉沉浸。

### 6. 领先的AI增强移动连接

领先的高通® X85 5G调制解调器-RF，搭载我们第四代高通® 5G AI处理器，AI推理速度提升30%，带来更可靠、精准、高效的5G连接；同时通过上行MIMO实现最快3.7Gbps的峰值速度。高通® FastConnect™ 7900移动连接系统，提供我们功能最强的Wi-Fi 7，由AI增强，功耗节省40%，并支持蓝牙和超宽带（UWB）。

> 所有对比均基于上一代产品。

## 核心特性

### 高通AI引擎
- **高通Hexagon NPU**：性能提升37%，每瓦性能提升16%
- **高通Oryon CPU**：首次搭载硬件矩阵加速

### 高通® 感知中枢（Sensing Hub）
- 高通感知中枢上首次集成**个人抄写员**和**个人知识图谱**，提供高度个性化的响应
- 新增**INT2和FP8**高精度数据类型支持

### CPU性能
- **高通Oryon CPU**：CPU性能提升20%，能效提升35%
- 高通Oryon CPU为定制设计，最高主频达**4.74GHz**，为全球最快的移动CPU速度

### GPU与功耗
- **Adreno GPU**：性能提升23%，能效提升20%，光线追踪性能提升25%
- **SoC整体功耗节省高达16%**，相当于为玩家额外增加1小时48分钟的游戏时间

### 高通Spectra™ AI ISP
- 全球首款支持APV录制的移动平台
- 全球首款配备三颗20位ISP的移动平台

### 骁龙 Elite Gaming 完整套装
- **虚幻引擎5完整支持**：将主机级画质和沉浸式游戏体验带到移动设备上
- **瓦片内存堆（Tile Memory Heap）**：智能优化内存使用和带宽
- **网格着色（Mesh Shading）支持**：允许开发者更高效地分组几何图形，实现更智能的GPU驱动渲染和功耗节省

### 高通X85 5G调制解调器-RF系统
- **极速下载速度**高达12.5Gbps，**上传速度**高达3.7Gbps
- **AI推理速度提升30%**，带来更智能、更可靠的移动体验

### FastConnect 7900移动连接系统
- 相比上一代，**功耗节省提升40%**
- **AI增强Wi-Fi**，游戏延迟降低最高50%

## 翻译术语说明

- **Agentic AI**：译为"智能体AI"，指能够自主理解用户意图并采取行动的AI助手
- **ISP**：图像信号处理器（Image Signal Processor），保留行业通用缩写
- **SoC**：系统级芯片（System on Chip），保留行业通用缩写
- **NPU**：神经网络处理器（Neural Processing Unit），保留行业通用缩写
- **GPU/CPU/AI**：均保留行业通用缩写
- 所有技术术语均参照高通中国官网及中文科技媒体的通用译法进行统一
